🗄️ Database Schema (6 Models)

👤 User

  • id (UUID)
  • name (String)
  • email (String, unique)
  • passwordHash
  • role (ADMIN|MANAGER|CASHIER)
  • createdAt, updatedAt

🏷️ Category

  • id (UUID)
  • name (String)
  • products (1:Many)
  • createdAt, updatedAt

📦 Product

  • id (UUID)
  • name (String)
  • sku (String, unique)
  • price (Float)
  • stock (Int)
  • category (FK)
  • movements, items (1:Many)

📊 InventoryMovement

  • id (UUID)
  • productId (FK)
  • type (STOCK_IN|SALE|ADJUSTMENT)
  • quantity (Int)
  • previousStock, newStock
  • createdBy (User ID)
  • createdAt

🛒 Transaction

  • id (UUID)
  • cashierId (FK to User)
  • totalAmount (Float)
  • items (1:Many)
  • createdAt

📋 TransactionItem

  • id (UUID)
  • transactionId (FK)
  • productId (FK)
  • quantity (Int)
  • unitPrice (captured at sale time)
  • subtotal
